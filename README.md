# Fast Forward Academy Founder Bingo

A mobile-friendly, single-page icebreaker Bingo game for the Fast Forward
Academy cohort.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The app is ready to deploy to Vercel as a standard Next.js project.
